# 🛡️ Administrator Guide & System Management

This guide explains system administration capabilities for users with the `ADMIN` role.

---

## 🔑 Admin Features & Responsibilities
- **Global Platform Dashboard** (`/admin`): Monitor platform statistics (total registered users, total assessments run, total consultations scheduled, total dermatologist reviews).
- **User & Role Management**: Inspect platform user directory and elevate/manage user credentials.
- **System Health Monitoring**: Access `/health` and `/readiness` endpoints to ensure PostgreSQL database connection pool health.
- **Admin Report Analytics**: Query `/api/reports/admin/summary` for platform usage summaries.
