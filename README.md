---

## 📌 Project Overview

A responsive React web application for managing skincare routines, consultations, and role-based access. The application includes a Landing Page, a Login Page with role switching, and three role-specific dashboards (User, Consultant, Admin).

---

## 🎯 Key Application Features

1. **Home / Landing Page (`/`)**: Overview of the platform and role options.
2. **Login Page (`/login`)**: Authentication form supporting role selection (`user`, `consultant`, `admin`) and quick demo login.
3. **Role-Based Dashboards**:
   - **User Dashboard (`/user`)**: Displays daily skincare routine checklist and recommended products.
   - **Consultant Dashboard (`/consultant`)**: Displays patient appointment requests with status approval toggles.
   - **Admin Dashboard (`/admin`)**: Displays user list with role management toggles.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, React Router v7
- **Styling**: Bootstrap 5, Custom CSS
- **State Management**: React Context API (`AuthContext`)

## 🚀 Running the Project Locally

1. **Clone the repository & checkout branch**:
   ```bash
   git clone https://github.com/springboardmentor23232a-eng/AI_Skin-Intelligence-Personalized-Skincare-Planner.git
   cd AI_Skin-Intelligence-Personalized-Skincare-Planner
   git checkout Akash-Prajapati
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Visit [http://localhost:5173](http://localhost:5173)
