# 🧴 AI Skin Intelligence

**AI Skin Intelligence** is a full-stack web application designed to provide personalized skincare guidance based on a user's skin assessment, concerns, and preferences.

The platform brings together **skin assessment, skincare recommendations, product discovery, ingredient intelligence, skincare routines, progress tracking, reports, notifications, and dermatologist/consultant functionality** in one application.

🌐 **Live Demo:** [AI Skin Intelligence](https://ai-skin-care.vercel.app)

---

## ✨ Features

### 👤 User Authentication

- User registration and login
- JWT-based authentication
- Google OAuth authentication
- Secure password hashing
- Role-based access

### 🔬 Skin Assessment

Users can upload a skin image and receive a skin assessment containing information such as:

- Skin health score
- Skin type
- Main skin concern
- Hydration
- Acne level
- Pigmentation
- Redness
- Skin texture
- Sensitivity
- Risk level
- Overall condition

Users can also view their previous assessment history.

> **Note:** The current image assessment implementation accepts and processes uploaded images, while the assessment values are currently generated by the application's assessment logic. A future version can integrate a trained computer-vision/ML model for image-based skin analysis.

### 🧴 Personalized Recommendations

The application provides personalized skincare recommendations based on the user's skin information and concerns.

Features include:

- Recommended skincare products
- Product suitability
- Alternative products
- Budget-based recommendations
- Product comparison

### 🧪 Ingredient Intelligence

Users can explore skincare ingredients and understand their purpose and suitability.

The ingredient system includes:

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd "AI SKIN CARE"
```

### 2. Install Node.js Dependencies

```bash
npm install
```

Install backend dependencies:

```bash
cd backend
npm install
cd ..
```

### 3. Install Python Dependencies

```bash
cd skin-assessment-engine
pip install -r requirements.txt
cd ..
```

### 4. Configure Environment Variables

Create your local `.env` files using the required configuration.

Example:

```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=skin_ai_db
DB_USER=your_database_user
DB_PASSWORD=your_database_password

JWT_SECRET=your_jwt_secret

GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
```

**Never commit real passwords, API keys, OAuth secrets, or database credentials to GitHub.**

## ▶️ Running the Application

### Start the Node.js Backend

```bash
node backend/server.js
```

### Start the FastAPI Service

```bash
cd skin-assessment-engine
uvicorn app.main:app --reload --port 8000
```

### Start the Frontend

The frontend is made using HTML, CSS, and JavaScript.

You can run it using **VS Code Live Server** or another local static web server.
