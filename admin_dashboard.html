pgAdmin 4 — How to view data

  1. Open pgAdmin 4 (Start Menu → pgAdmin 4)
  2. Connect to localhost with user postgres
  3. Expand: Databases → skin_intelligence → Schemas → public → Tables
  4. Right-click users → View/Edit Data → All Rows
  5. You'll see all registered users with their hashed passwords, roles and timestamps!
