About

AI-Powered Skin Intelligence for Everyone

GlowSense AI is a comprehensive skin intelligence platform built for B.Tech AI/ML demonstration. It combines a Node.js + Express backend, PostgreSQL database, and a Python FastAPI ML service to deliver real, data-driven skin health assessments.

The platform supports four roles — users, consultants, dermatologists, and administrators — each with a dedicated dashboard tailored to their responsibilities.

Node.js + Express REST API
PostgreSQL with JWT authentication
Python FastAPI ML service
scikit-learn model integration
Frontend HTML / CSS / JavaScript
Backend Node.js + Express
ML Service Python FastAPI + scikit-learn
Database PostgreSQL

GlowSense AI provides informational skincare insights and does not provide a medical diagnosis. Consult a qualified dermatologist for medical concerns.
